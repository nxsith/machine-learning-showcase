# Machine Learning Projects

### Three practical learning projects across classification and computer vision

A portfolio overview of my CodeAlpha Machine Learning Internship tasks, covering structured data modelling and handwritten digit recognition.

## Projects at a glance

| Project | Problem | Approach |
| --- | --- | --- |
| Credit Scoring Model | Classifying historical credit risk | Logistic Regression and Random Forest |
| Handwritten Character Recognition | Recognising handwritten digits | Convolutional Neural Network with MNIST |
| Disease Prediction from Medical Data | Classifying historical diabetes-dataset outcomes | Comparison of three machine-learning models |

## 1. Credit scoring

An educational classification project exploring how historical lending data can be prepared and used to compare predictive models. The focus is the modelling workflow and evaluation, rather than making real lending decisions.

## 2. Handwritten digit recognition

A computer vision project using a convolutional neural network to recognise MNIST handwritten digits. It demonstrates the transition from tabular classification to image-based learning.

## 3. Disease classification

A structured medical-dataset exercise comparing multiple models on historical diabetes outcomes. This is a learning task, not a diagnostic product.

## Skills demonstrated

- Python-based machine-learning development.
- Dataset preparation and exploration.
- Training and comparing classification models.
- Neural-network-based image recognition.
- Evaluation, visual outputs, and documentation of limitations.

## Interpretation and limitations

No performance figures are claimed in this showcase. Results depend on dataset quality, splits, preprocessing, and evaluation choices. These educational demonstrations are **not intended for real credit, medical, or clinical decisions**.

## About this repository

This repository contains only this project overview. It does not include datasets, model files, notebooks, or source code.
